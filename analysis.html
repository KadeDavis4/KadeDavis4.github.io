Business Questions

How does occupancy change seasonally and what can we learn from it?
Which neighborhoods are oversaturated or undersupplied?
How many new hosts are entering into each neighbourhood? Are hosts entering in the right ones?

Company Link

Seattle Airbnb Market Analysis

Key Findings

Demand is centered around late summer: Occupancy rests at around 40% most of the year, climbing steadily to 60% throughout summer and into october, before sharply dipping down in november. This is a valuable insight for seasonal hosts, displaying that there is a clear pattern for high return 3-6 month seasonal Airbnb properties ending in the November season. This information can be used to promote seasonal hosting for maximum value.

Some neighborhoods are undersupplied: The southern neighborhoods show both above average occupancy and above average pricing despite not being typically popular areas. This suggests unmet demand that can be aided by host recruitment. Magnolia also seems to have very high demand while being a popular area, however we can see the host increase matches this need already.

Some host growth is concetrated in saturated areas: We can see that Lake City, Northgate, Interbay, Delridge, and the University District have high host increases despite fairly low demand indicators. This coupled with the fact that some areas being undersupplied means that new hosts are entering areas that are statistically worse for new competetion, and could use direction.

Process

To create this analysis, I first had to find a public Airbnb database and install general data from 2025 and 2026, calendar data, and geographic data. I then used python with the pandas library to organize the data into 2 usable csv files, one for general data joined with neighborhood data, and one for calendar data, also joined with neighborhood data. I put these 2 files and a the geographic data into tableau, and carefully designed the dashboard above with a goal of balancing detail with usable and readable information.
