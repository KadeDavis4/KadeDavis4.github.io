Business Questions

How does Airbnb occupancy change seasonally and what can we learn from it?
Which neighborhoods are oversaturated or undersupplied?
How many new hosts are entering into each neighbourhood? Are hosts entering in the right ones?

Company Link

Seattle Airbnb Market Analysis

Key Findings

Demand is centered around late summer: Occupancy rests at around 40% most of the year, climbing steadily to 60% throughout summer and into october, before sharply dipping down in november. This is a valuable insight for seasonal hosts, displaying that there is a clear pattern for high return 3-6 month seasonal Airbnb properties ending in the November season. This information can be used to promote seasonal hosting for maximum value.

Some neighborhoods are undersupplied: The southern neighborhoods show both above average occupancy and above average pricing despite not being typically popular areas. This suggests unmet demand that can be aided by host recruitment. Magnolia also seems to have very high demand while being a popular area, however we can see the host increase matches this need already.

Some host growth is concentrated in saturated areas: We can see that Lake City, Northgate, Interbay, Delridge, and the University District have high host increases despite fairly low demand indicators. This coupled with the fact that some areas being undersupplied means that new hosts are entering areas that are statistically worse for new competetion, and could use direction.

Process

To create this analysis, I first sourced public data from InsideAirbnb, pulling listings and calendar data from 2025 and 2026, as well as neighborhood geographic data. Using Python and pandas, I processed the raw compressed files, deriving occupancy rates from availability data, cleaning price strings to numeric values, creating a host delta metric by comparing listing counts across years, and aggregating everything to neighborhood level. I then dissolved geographic data into district level boundaries using geopandas, before merging the result with the cleaned data into a single geojson for mapping. The final dashboard was built in Tableau, designed to balance valuable detail with readability and simplicity in a single interactive view.
